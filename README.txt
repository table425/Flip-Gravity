FLIP GRAVITY — UPDATED EDITION

Run locally: open index.html in a modern browser. Keep the GAME folder and the supplied root asset files together in the extracted Flip-Gravity-main folder.

Controls: A/D or Left/Right to move; W, Space, or Up to flip gravity; Escape to pause. Touch controls appear on smaller screens.

This edition includes 16 stages, scrolling parallax scenery, curved portal doors, rocky grass platforms, and spring/bouncy platforms.
